## 1번 작업 기록 · 2026-11-02

- 사용자 지시에 따라 루트 `AGENTS.md`를 만들고, 하네스 및 두 룰의 `.draft` 접미사를 제거해 활성 기준으로 연결한다. 정책·프롬프트·금액표·룰 버전은 유지한다.
- `vite.config.js`의 Node `process`를 명시적으로 import해 기존 `no-undef` 오류를 해결한다.
- `.gitignore`에서 `.env`·`.env.*`를 제외하고 빈 `.env.example`만 공유한다. 현재 실행에는 키가 필요 없고 서버 키 로딩은 후속 구현이라는 점을 명시한다.
- `.nvmrc`에 Node 24를 지정하고 README에 설치·실행·검증 방법을 정리한다. 의존성·잠금 파일과 기능 코드는 변경하지 않는다.
- 검증 완료: `npm run lint` 통과, `npm run build` 통과, `git diff --check` 통과.
- `npm run dev -- --strictPort`로 `http://localhost:5173/` 기동 및 HTTP 200 응답을 확인했다. 샌드박스의 포트·접속 제한 때문에 승인된 로컬 실행 환경에서 확인했으며 검증 후 이 작업에서 실행한 서버를 종료했다.
- `.env`·`.env.local`·환경별 `.env.*`·하위 서버 디렉터리의 키 파일이 ignore되고 루트/하위 `.env.example`은 허용됨을 검사했다. 실제 `.env`나 키는 생성하지 않았다.
- AGENTS·README·문서 링크, 두 LLM 프롬프트·금액표, 하네스 제품 정책 보존을 확인했다. `src/`, 의존성·잠금 파일은 변경하지 않았다. 검증 환경은 Node 24.19.0, npm 11.17.0이다.

이 단계는 Firebase 연결·Node API·LLM 호출·모델 학습·Figma 수정·기능 화면 구현·배포를 포함하지 않는다. 현재 브랜치 `main`을 유지하고 커밋·push는 수행하지 않는다.

## 야간 작업 체크포인트 · 2026-11-02

- 1번 하네스/설정 변경을 `4c40c69`로 `origin/main`에 푸시했다.
- IndexedDB에 사용자·설정·질문·답변·첨부·포인트 원장·과거 스냅샷·게시글 차단 저장소를 만들었다. 두 계정과 각각 1,000P 시작 원장을 멱등 시드하고 답변자 과거 포인트 이력을 잔액 계산에서 분리했다. 테스트 비밀번호는 브라우저 번들에만 포함하고 저장소에 쓰지 않는다.
- 데모 로그인에서 정확한 이메일·비밀번호 비교를 구현했다. 브라우저에서 질문자 로그인→중국어 UI, 로그아웃→기기 영어 UI, 비밀번호 오타 거부, 답변자 로그인→베트남어 UI를 확인했다.
- 홈·질문/게시판 선택·게시판·질문 상세·질문 작성·포인트 화면의 1차 UI를 연결했다. Figma 원본 로그인 로고, 카테고리 아이콘, 하단 탐색바, 질문/게시판 선택 아이콘을 프로젝트 자산으로 저장했다. Figma 원본 파일은 수정하지 않았다.
- 브라우저에서 질문 작성과 새로고침 후 유지, 답변자 1,000P와 과거 -2,000P 표기, 1,000P 전환 시 토스트와 잔액 유지 동작을 확인했다. 작성한 테스트 질문은 브라우저 로컬 데이터에만 있다.
- 질문 등록 보상은 명시적 기본 경로(일반 100P/긴급 150P)이며 AI 분류 호출은 아직 없다. 답변 작성·채택·LLM·7일 자동 채택·전체 네 언어 시각 검수는 미완료다. Figma의 `07_Q&A_상세`(539:369)는 이름과 달리 게시판 목록 화면으로 확인하여 상단 바·상태 필터·카드 배치를 반영했다. 원본 질문 예시 글은 시드하지 않았다.
- 등록 완료 화면은 Figma 프레임(844:807)을 연결하고 실제 저장된 기본 보상액을 표시한다. 질문 첨부는 신규·수정 시 개수/형식/용량을 검증하고, 삭제는 첨부를 제거하면서 질문을 논리 삭제한다. 질문 등록 후 보상 스냅샷은 이후 긴급도 수정을 해도 다시 계산하지 않는다. 브라우저에서 테스트 PNG를 기존 질문에 첨부한 뒤 저장·새로고침해 첨부가 유지되는 것을 확인했다. 첨부 제거와 질문 삭제는 별도 검증이 남아 있다.

## 베트남어 UI·모션 보정 · 2026-11-02

- 질문 작성의 베트남어 카테고리 8개를 원래 4×2 배치 안에서 줄이지 않고 표시하도록 아이콘·글자 크기와 간격을 조정했다. 모바일 브라우저에서 각 글자의 실제 경계가 버튼 안에 들어오는 것을 확인했다. 다른 언어의 아이콘·글자 크기는 유지한다.
- 홈·게시판·질문 작성·포인트·등록 완료 상단의 프로필/알림 기호를 같은 SVG 아이콘으로 교체했다. 알림은 현재 빈 상태 화면으로 연결하고, 마이페이지는 실제 데모 닉네임·이메일과 아바타를 표시한다.
- 전달받은 `K&A 프로토타입 (Copy) (1).html`의 현재 화면에 해당하는 모션 수치와 easing을 옮겼다: 질문/게시판 선택 팝업 `.22s ease-out`, 하단 작성 버튼 회전 `.2s`, 전환 시트 `.22s ease-out`, 토스트 `.2s ease-out`, 등록 완료 색종이 `1.9s cubic-bezier(.25,.6,.45,1)`. `prefers-reduced-motion`도 지원한다. iOS 제어 센터 재현은 현재 앱 화면 흐름에 연결하지 않았다.

## 마이페이지 시연 초기화 · 2026-11-02

- Figma `01_마이_페이지`(849:2444)의 프로필·내 정보 3개·리워드 관리 1개·앱 설정 2개·로그아웃 목록을 반영했다. 설정 행은 디자인만 표시하고, 기존 로그아웃 동작은 유지한다.
- 붉은색 `전체초기화`는 첫 클릭 후 3초 안에 다시 클릭해야 실행된다. IndexedDB의 계정·질문·답변·첨부·설정·포인트 원장/스냅샷·차단 데이터를 비운 뒤 두 데모 계정과 각각 1,000P, 답변자의 과거 표시 스냅샷을 재생성하고 로그인 화면으로 이동한다. 초기화 첫 클릭만 별도 포트의 비어 있는 데모 환경에서 확인했고 실제 삭제 동작은 현재 브라우저 데이터에 실행하지 않았다.
- 새 브라우저 원점의 첫 접속에는 질문 시드가 없음을 확인했다. 이전 UI 검수에서 생성한 특정 `시연 동작 확인 질문`은 ID·제목·작성자가 모두 일치하는 경우에만 앱 초기화 과정에서 논리 삭제하고 첨부를 제거한다. 다른 작성글에는 이 정리가 적용되지 않는다.
