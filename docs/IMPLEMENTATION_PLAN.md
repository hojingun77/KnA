## 1번 작업 기록 · 2026-11-02

- `vite.config.js`의 Node `process`를 명시적으로 import해 기존 `no-undef` 오류를 해결한다.
- `.gitignore`에서 `.env`·`.env.*`를 제외하고 빈 `.env.example`만 공유한다. 현재 실행에는 키가 필요 없고 서버 키 로딩은 후속 구현이라는 점을 명시한다.

- 검증 완료: `npm run lint` 통과, `npm run build` 통과, `git diff --check` 통과.
- `npm run dev -- --strictPort`로 `http://localhost:5173/` 기동 및 HTTP 200 응답을 확인했다. 샌드박스의 포트·접속 제한 때문에 승인된 로컬 실행 환경에서 확인했으며 검증 후 이 작업에서 실행한 서버를 종료했다.
- `.env`·`.env.local`·환경별 `.env.*`·하위 서버 디렉터리의 키 파일이 ignore되고 루트/하위 `.env.example`은 허용됨을 검사했다. 실제 `.env`나 키는 생성하지 않았다.
- AGENTS·README·문서 링크, 두 LLM 프롬프트·금액표, 하네스 제품 정책 보존을 확인했다. `src/`, 의존성·잠금 파일은 변경하지 않았다. 검증 환경은 Node 24.19.0, npm 11.17.0이다.

이 단계는 Firebase 연결·Node API·LLM 호출·모델 학습·Figma 수정·기능 화면 구현·배포를 포함하지 않는다. 현재 브랜치 `main`을 유지하고 커밋·push는 수행하지 않는다.

## 마이페이지 시연 초기화 · 2026-11-02

- 작성자 질문의 삭제 확인을 브라우저 기본창에서 앱 내부 중앙 모달로 바꿨다. 취소 시 질문 유지와 브라우저 기본창 미표시를 확인했다. 리워드 화면 상단의 `⋮`는 사용자 요청에 따라 제거했다. 실제 삭제 버튼은 기존 논리 삭제 함수에 연결되며, 검수 중 시연 데이터를 삭제하지 않았다.

## 게시글 상세 답변 입력 · 2026-11-02

- Figma `답변자_흐름`의 `comment-input 1`(885:178)을 상세 화면 하단 폭에 맞춰 배치하고 원본 SVG 배경·전송 아이콘을 적용했다. 네 지원 언어의 입력 안내·전송 문구를 연결했다.
- 답변 등록을 IndexedDB `answers` 저장소에 연결하고 상세 목록·홈·게시판의 실제 답변 수를 표시한다. 별도 로컬 포트에서 중국어 질문 등록 → 베트남어 계정 답변 등록 → 새로고침 후 유지와 답변 수 1 반영을 확인했다. AI 평가·채택·보상은 이번 입력 UI의 동작 범위가 아니다.
- 답변 입력창의 자두색 포커스 테두리를 제거했다. 공통 `DeviceFrame` 상태 표시줄은 Figma `01_앱_로딩`(400:277)의 시간·노치·오른쪽 통신/배터리 SVG와 좌표/크기로 교체했다. 로그인 및 게시글 상세에서 아이콘 간격, 입력창 클릭 후 테두리 미표시를 확인했다.

## 검색 화면 · 2026-11-02

- Figma `search-screen 1`(888:182)의 검색 입력창·최근 검색어 구성을 기존 앱 공통 상태 표시줄과 네 언어에 맞춰 `/search`에 연결했다. 홈 검색창에서 진입하고, 피그마의 임의 상태 표시줄과 키보드·예시 검색기록은 UI 데이터로 넣지 않는다.
- 로그인 계정별 최근 검색어를 IndexedDB 설정에 저장한다. 최초 목록은 비어 있으며 제출 시에만 추가한다. 제목·본문·카테고리 로컬 검색, 최근 검색어 선택·개별 삭제·전체삭제를 제공한다. 별도 포트에서 첫 방문의 빈 목록, 검색 결과, 제출 후 최근 기록 표시, 전체삭제 후 빈 목록을 확인했다.
