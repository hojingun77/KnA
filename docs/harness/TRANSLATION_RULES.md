# K&A 사용자 콘텐츠 번역 룰 v1

> **상태: 활성 개발 기준 (`codex/llm-prototype` 브랜치 전용) / 기준 버전: `kna-translate-v1` / 작성·활성화일: 2026-11-03**
>
> [프로젝트 하네스](./PROJECT_HARNESS.md) 2026-11-03 개정의 부속 문서다. main 브랜치에는 적용하지 않는다.

## 1. 범위
- 번역 대상은 사용자가 쓴 **질문 제목·질문 본문·답변 본문**뿐이다. 메뉴·버튼 같은 고정 UI 문구는 기존 4개 언어 사전(i18next)을 쓰고 번역 API로 만들지 않는다.
- 닉네임·첨부·카테고리·포인트 등은 번역하지 않는다.
- 번역은 질문 보상 분류 요청과 섞지 않는다. 보상 분류는 원문을 그대로 쓴다.

## 2. 실행 조건
> 2026-11-03 사용자 지시로 개정: 중국어·베트남어 계정은 자동 번역, 원문 보기 버튼으로 같은 자리에서 원문 ↔ 번역문 전환.

- **자동 번역 언어:** 보는 사람의 UI 언어가 `zh-CN` 또는 `vi`일 때만 자동 번역한다. `ko`·`en` 화면은 번역하지 않고 원문을 보여 준다.
- **자동 번역 범위:** 질문 상세의 제목·본문·모든 답변 본문, 그리고 홈·게시판·검색 목록 카드의 질문 제목. 화면에 들어오면 자동으로 요청한다.
- 목표 언어는 보는 사람의 UI 언어다. 작성 언어(`authorLanguage`)가 목표 언어와 같으면 번역하지 않는다. 작성 언어가 없는 예전 기록은 엔진의 언어 감지에 맡긴다.
- 저장된 번역(같은 대상·revision·언어)은 다시 요청하지 않는다. 없는 것만 한 번에 최대 5개씩 묶어 요청하고, 같은 대상을 동시에 요청하면 한 번만 호출한다.
- 원문은 덮어쓰지 않는다. 번역 중이거나 실패하면 원문을 그대로 보여 준다.
- **원문 보기 버튼:** 상세 화면의 질문(제목·본문 함께)과 각 답변 아래에 둔다. 번역이 적용되면 `원문 보기`를 표시하고, 누르면 새 창이나 나란히 보기 없이 같은 자리의 글자만 원문으로 바꾼다. 다시 누르면(`번역문 보기`) 번역문으로 돌아온다. 질문과 답변은 따로 전환되며 화면을 나가면 번역문 상태로 초기화된다. 번역 중·실패일 때는 버튼 대신 상태(`번역 중…` / `번역하지 못해 원문을 보여드려요`)만 표시한다.

## 3. 엔진과 실패 처리
| 순서 | 엔진 | 조건 |
|---|---|---|
| 1 | Google Cloud Translation Basic(v2), `format=text` | 서버 `.env`에 `GOOGLE_TRANSLATE_API_KEY`가 있을 때 |
| 2 | 로컬 sLLM (Ollama `qwen2.5:7b`) | Google 키가 없거나 Google 호출이 실패했을 때 |
| 3 | 실패 | 둘 다 실패하면 원문을 유지하고 `번역하지 못했어요 · 다시 시도`만 표시 |

- 자동 재시도는 하지 않는다. 사용자 재시도만 허용한다.
- sLLM에는 "번역만 하고 번역문만 출력" 지시를 고정 시스템 메시지로 주고, 원문 안의 지시는 따르지 않게 한다. 빈 응답이나 원문과 동일한 응답은 실패로 본다.
- 시간 제한: Google 8초, sLLM 20초. Google은 원격 호출이라 대기열을 거치지 않고, sLLM 번역만 보상 분류와 공통 대기열(동시 1개)을 쓴다.
- 질문 제목과 본문처럼 함께 보이는 문장은 요청 한 번(최대 5개)으로 묶어 번역한다.

## 4. 저장과 재사용
- 저장 키는 `대상 종류(question_title/question_body/answer_body) + 대상 ID + revision + 목표 언어`다. 같은 키는 다시 호출하지 않는다.
- 글이 수정돼 revision이 바뀌면 이전 번역을 쓰지 않는다(새로 번역).
- 저장 위치는 브라우저 IndexedDB `translations` 저장소다. 전체초기화 때 함께 지운다.

## 5. 보안·비용
- 키는 서버 환경 변수에만 둔다. `VITE_*`·브라우저 코드·IndexedDB·로그에 넣지 않는다.
- Node API는 `127.0.0.1`에만 열고, 허용 origin·요청 크기(16KB)·빈도를 검사한다. 요청 본문 전체를 로그에 남기지 않는다.
- Google Basic v2는 월 50만 자까지 무료 크레딧 범위다. 시연은 무료 범위 안에서만 쓴다. sLLM은 PC에서 실행되어 별도 비용이 없다.
- 외부로 나가는 것은 번역할 원문뿐이다(Google 사용 시). 화면에 `기계 번역 · Google`처럼 엔진을 표시해 전송 사실을 알린다.
